# Estrutura de Dados - Aula 1 (Exercícios 5 a 9)

Programas em C feitos como exercício da disciplina de Estrutura de Dados (UNISAL).

| Pasta | Exercício | Conteúdo |
|-------|-----------|----------|
| ex5 | 5 | Macros (#define) |
| ex6 | 6 | typedef |
| ex7 | 7 | sizeof() nos tipos primitivos |
| ex8 | 8 | Constantes de limits.h |
| ex9 | 9 | Programa completo: macros + typedef + tipos de tamanho fixo |

## Como compilar e rodar

```bash
gcc -o prog ex5/ex5.c && ./prog
gcc -o prog ex6/ex6.c && ./prog
gcc -o prog ex7/ex7.c && ./prog
gcc -o prog ex8/ex8.c && ./prog
gcc -o prog ex9/ex9.c && ./prog
```
